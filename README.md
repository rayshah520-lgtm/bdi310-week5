# The Room

A small web page built as teaching material for BDI310 Creative Coding at Seneca Polytechnic.

A slider stands in for a heat sensor. The page turns the reading into degrees, decides whether the room needs the heater, the vent or nothing, keeps the heater off while the window is open, and averages the last five readings. It also asks a free weather service for the temperature outside.

## Files

- `index.html` - what is on the page
- `styles.css` - how it looks
- `script.js` - what it does

## Using it

Fork the repository, then clone your fork and open the folder in VS Code.

Open `index.html` with Live Server: right-click the file and choose **Open with Live Server**. Double-clicking the file also works.

The outside temperature comes from [Open-Meteo](https://open-meteo.com), which is free and needs no account. With no internet connection, the rest of the page still works.

## Reuse
